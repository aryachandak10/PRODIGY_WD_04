# Personal Portfolio Website 🌐

This is a simple and responsive personal portfolio website built using **HTML** and **CSS**.  
The website showcases my skills, background, education, and professional aspirations as a web developer.

---

## 🚀 Features

- Clean and attractive user interface
- Home section with headline, profile image, and skills summary
- About Me section with background, education, and experience
- Beginner-friendly and easy to customize
- Responsive layout for different screen sizes

---

## 🛠️ Technologies Used

- HTML5  
- CSS3
